HOW TO PUBLISH ON GITHUB PAGES
1. Create a public repository (e.g. tic-tac-toe).
2. Upload index.html, icon-192.png, icon-512.png, manifest.webmanifest to repository root.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open https://YOURUSERNAME.github.io/tic-tac-toe/

GAME FEATURES
- VS COMPUTER (Easy / Normal / Hard unbeatable AI)
- TWO PLAYERS on one phone / desktop
- Arcade synth sound effects (Sound ON/OFF), no audio files required
- Keyboard 1–9 support, touch controls
- Local settings saved to browser
- Scores for current session
- Responsive mobile design, optional Add to Home Screen
